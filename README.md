# Ondas-cotidianas

Este proyecto fue conformado a traves de la ingenieria inversa del encargo 06 del curso DPPI. 
El encargo buscaba la interacción de la imagen con el sonido, al final utilice como referencia la naturaleza y como esta actua en relacion a su entorno, entonces pase directamente del sonido a la imagen, este ejercicio pude presenciar sonidos repetitivos donde las formas que se van creando en cierto punto se vuelven a encontrar, generando formas y vibraciones parecidas. 

Para el desarrollo ocupe como referente el programa de FL STUDIO, ya que este posee distintos canales para el desarrollo de nuevos sonidos, trate de replicar la escencia de un programa de desarrollo de musica para aterrizarlo y dejarlo a disposicion de la creación de imagenes. 

Para el uso del HTML no se requiere de una previa instalación, si es cierto que para el uso de cámara en tiempo real es necesario abrirlo desde un navegador web.

        ESTRUCTURA PARA EL USO 

Componentes: 
 1. Osciladores

 2. Fuentes

 3. Amplificadores con filtros (Ataque - Caida - Sostén  - Suelta)

 4. Filtros

 5. Filtros Envolventes

 6. Generador de frecuencias bajas (LFO)

 7. Color (orientado a el movimiento del grano y saturación de este)

 8. Ventana (opciones para el recuadro de la visualización)

 9. Rack de Plugins(Delay - Reverb - Chorus - Distorcion)

 10. Potenciometros de cada plugin (zona inferior a esta misma)

 11. Zona de pistas (zona para agregar sonidos)

12. Zona de teclado / Zona de PAD (Esta zona esta orientada a la composicion de nuevos sonidos, se pueden integrar sonidos y ver como estos interactuan directo con la imagen, se puede usasr el teclado fisico del dispositivo para poder manipularlo)

13. Modulo para recordar patrones de sonidos. (se trato de replicar el sistema de maqueta del FL, donde se puedenn ver patrones de tiempo, recordar grabaciones, utilizar el metronomo como guía, entre otras cosas)

14. Maqueta (sirve para exportar archivos nativos desde FL, si un productor te envia una pista en ciertos parametros la interfaz deberia de desglosar los sonidos y dividirlos según su intención)

            Visualización

Para la visualización se trato de abarcar toda forma que lograba generar el sonido, desde placas de vibraciones, hasta interacciones con la cámara integrada del dispositivo, se añadieron al rededor de 15 formas de visualización de sonido.
        
1.Ondas
2.Orbitas
3.EStereo (espectograma)
4.Placa de vibración Chladni
5.Cámara (distintas formas de visualización, Deep Map, grano, puntos, ascci, entre otras)
6. Cubo (ondas dentro de un volumen)
7. Gravedad (interaccion con el sonido y la acción de este.)
8. Mapa de volumen en el tiempo


       
       
            OBJETIVO

La principal idea era replicar un sistema de facil entendimiento para la formación de imagenes a través del sonido, hata el momento no esta terminado, ya que me gustaria poder terminar de agregar un renderizado para que este genere visuales en tiempo real según el espectro del sonido, de igual manera se logro formar una plataforma de sonidos interactivos que terminan pasando a la imagen.
