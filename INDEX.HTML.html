Cómo traer una maqueta de FL Studio:

  1. Stems: File → Export → WAV y activa “Split mixer tracks”. Sale un WAV por cada pista del mixer, con su sonido real.
  2. Notas: File → Export → MIDI file. Trae las notas de cada canal y el tempo.
  3. Arrastra los WAV y el .mid a este recuadro, o usa los botones. Con EJEMPLO ves cómo funciona sin archivos.
